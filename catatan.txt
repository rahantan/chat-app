## Pola yang perlu kamu ingat
Handler
↓
"Request ini melakukan apa?"
↓
Get / List / Create / Update / Delete
Checkout / Cancel / Pay / Login / Register


Service
↓
"Use case/bisnisnya melakukan apa?"
↓
Get / List / Create / Update / Delete
Checkout / Cancel / Pay / CheckStock / ReduceStock


Repository
↓
"Data apa yang perlu dicari/diubah?"
↓
FindByID / FindByUserID / FindDetailByID
FindAll / ExistsByID
Create / Update / Delete


## Contoh paling jelas:
GET /orders/:id

Handler
GetOrder()
    ↓

Service
GetOrderByID()
    ↓

Repository
FindByID()
